┌──────────────────────────────────────────────────────────────┐
│  DEMO MODE (No AWS Required)                                 │
└──────────────────────────────────────────────────────────────┘

  1. Install dependencies:
     $ npm install

  2. Copy environment file:
     $ cp .env.example .env

  3. Start the server:
     $ npm start

  4. Open browser:
     → http://localhost:3000

  5. Click the button:
     → "🚀 Run Demo Analysis"

  ✅ That's it! No AWS credentials needed.

┌──────────────────────────────────────────────────────────────┐
│  SWITCHING TO AWS MODE                                       │
└──────────────────────────────────────────────────────────────┘

  1. Edit .env:
     DEMO_MODE=false
     AWS_REGION=us-east-1
     S3_BUCKET_NAME=your-bucket
     DYNAMODB_DOCUMENTS_TABLE=government-documents
     DYNAMODB_USERS_TABLE=user-profiles

  2. Set up AWS resources (see DEPLOYMENT_CHECKLIST.md)

  3. Restart server:
     $ npm start
