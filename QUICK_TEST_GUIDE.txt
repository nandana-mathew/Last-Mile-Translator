  QUICK TEST GUIDE - Language Translation Feature
═══════════════════════════════════════════════════════════════

STEP 1: Install & Run
─────────────────────
npm install
npm start

Wait for: "🚀 Last-Mile Translator API running on port 3000"

STEP 2: Open Browser
────────────────────
http://localhost:3000

STEP 3: Test Language Switching
────────────────────────────────
1. Click "हिंदी" button → Wait 2-3 seconds
   ✓ All policy titles change to Hindi
   ✓ State/category names in Hindi
   ✓ Descriptions in Hindi

2. Click "ಕನ್ನಡ" button → Wait 2-3 seconds
   ✓ Everything changes to Kannada

3. Click "मराठी" button → Wait 2-3 seconds
   ✓ Everything changes to Marathi

4. Click "தமிழ்" button → Wait 2-3 seconds
   ✓ Everything changes to Tamil

5. Click "English" button
   ✓ Back to English

STEP 4: Test Policy Detail Page
────────────────────────────────
1. Select Hindi (हिंदी)
2. Click any policy card
3. New page opens completely in Hindi:
   ✓ Back button in Hindi
   ✓ Summary in Hindi
   ✓ Key Changes in Hindi
   ✓ Personal Impact in Hindi

STEP 5: Test Persistence
─────────────────────────
1. Select Kannada
2. Press F5 (refresh)
3. Page loads in Kannada automatically

═══════════════════════════════════════════════════════════════
  TROUBLESHOOTING
═══════════════════════════════════════════════════════════════
Problem: Nothing translates
Solution: Check browser console (F12), refresh page

Problem: Translations are slow
Solution: Normal! Wait 2-3 seconds after clicking language

Problem: Some items don't translate
Solution: Translation API might have failed, try again
